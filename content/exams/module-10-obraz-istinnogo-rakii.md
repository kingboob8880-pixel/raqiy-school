1. Сколько качеств перечисляет урок в портрете истинного раки?
- [ ] Три: знание, деньги, слава
- [x] Шесть: знание, такъва, ихляс, присутствие сердца, рахма, таваду'
- [ ] Девять: по числу запретов
- [ ] Одно: присутствие сердца

2. Что такое таваккуль согласно уроку?
- [ ] Пассивное ожидание без действий
- [x] Упование на Аллаха вместе с взятием причин
- [ ] Уверенность в собственном методе
- [ ] Обращение к праведным джиннам

3. Как грехи влияют на рукью раки?
- [ ] Никак — руки есть руки
- [ ] Грехи усиливают рукью скоростью
- [x] Грехи ослабляют рукью; раки сторонится их и совершает вуду перед сеансом
- [ ] Грехи важны только для пациента

4. Чем присутствие сердца при чтении похоже на разницу в намазе?
- [ ] Ничем — это разные навыки
- [x] Слова одинаковы, но один стоит перед Аллахом сердцем, а другой лишь двигает телом
- [ ] Присутствие сердца не требуется для рукьи
- [ ] Важно только правильное произношение

5. Как истинный раки относится к исцелению, которое не принесло ему денег?
- [ ] Считает такого пациента неблагодарным
- [x] Радуется исцелению и не ревнует, если помог другой чтец
- [ ] Требует оплату задним числом
- [ ] Скрывает метод, чтобы не потерять клиентов

6. О чём напоминает скромность (таваду') истинного раки?
- [ ] Что он лучше других чтецов
- [x] Чем больше он знает, тем яснее видит, как мало знает, и что исцелил Аллах, а не он
- [ ] Что нужно собирать отзывы для рекламы
- [ ] Что результат зависит от лекаря
