1. Сколько ступеней практики в паспорте и какая из них финальная?
- [ ] Две: чтение на себе и чтение на всех желающих
- [ ] Три: себя, близкие, самостоятельный приём без наставника
- [x] Четыре: себя → близкие с согласия → добровольцы под наблюдением → супервизированный приём
- [ ] Пять: включая стажировку у другого раки

2. Что технически фиксирует допуск к самостоятельному приёму (ступень 4)?
- [ ] Диплом о прохождении всех тестов модулей
- [x] Три разобранных случая со статусом «принято» через форму супервизии + устная защита двух из них
- [ ] Устная договорённость с наставником
- [ ] 100 записей в дневнике без проверки

3. Что требует вход на ступень «Близкие с согласия», кроме закрытой ступени 1?
- [ ] Только желание близких
- [ ] Пройденный Модуль 9
- [x] Модули 1–6 пройдены; согласие каждого объяснено («учебная рукья»)
- [ ] Разрешение администратора сайта

4. По каким полям ведётся запись случая — и почему порядок строгий?
- [ ] Свободный рассказ, как помнится
- [ ] По десяти критериям программы
- [x] Девять шагов формы супервизии: сначала слова пациента, потом выводы — иначе вывод ставится до опроса
- [ ] Только жалоба и результат

5. Чем оценивает наставник сеанс в паспорте?
- [ ] Процентами эффективности из книги «Сравнение сильного со слабым»
- [x] Восемью компонентами силы (Модуль 5) по уровням 0–3; проценты из книги — иллюстрация, не измеритель
- [ ] Числом изгнанных за сеанс
- [ ] Скоростью чтения

6. Какие два случая выносятся на защиту?
- [ ] Два самых лёгких и коротких
- [ ] Два последних по времени
- [x] Два из трёх принятых, из разных корневых групп (например, сглаз + сихр)
- [ ] Любой один случай, дважды

7. Что является безусловной несдачей защиты?
- [ ] Длинный рассказ с самокритикой
- [ ] Отсутствие результата («ничего не изменилось»)
- [x] Проигнорированный красный флаг или расхождение устного рассказа с принятым письменным разбором
- [ ] Вопрос наставника, на который нет ответа
