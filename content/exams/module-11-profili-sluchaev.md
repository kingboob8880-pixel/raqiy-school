1. Чем профиль A₂ отличается от профиля C при большой давности болезни?
- [ ] Ничем: давность всегда означает корневой случай
- [x] При A₂ годы болезни, но один доминирующий слой и нет договора, истихваза и рабта; C — это корень с договором или иным корневым поражением
- [ ] A₂ требует 7+ сеансов, а C закрывается за один
- [ ] A₂ — это только дети, C — только взрослые

2. Какие семь условий описывают профиль A₁?
- [ ] Возраст, пол, вес, стаж, зона, вид, сезон
- [x] Один тип без слоёв, острое начало, одна локализация, видимый выход, нет договора, якын пациента, точный уровень лекаря
- [ ] Вода, масло, мёд, соль, уксус, свет, тишина
- [ ] Только наличие свидетелей и согласия

3. Что наблюдается в каждое из трёх окон проверки — 72 часа, 7 дней, 21 день?
- [ ] Только настроение пациента
- [x] 72 часа — сон, аппетит, намаз, тревога, возврат симптома; 7 дней — подёргивания, зуд, тяжесть в затылке, сны; 21 день — устойчивость функции
- [ ] 72 часа — повторный сеанс, 7 дней — новый диагноз, 21 день — закрытие карточки
- [ ] Окна не отличаются друг от друга

4. Какие признаки означают, что облегчение не равно завершению?
- [ ] Пациент сказал «стало легче»
- [x] Подёргивания и зуд, тяжесть в затылке, «переезд» симптома в грудь, отсутствие функции, облегчение только через слёзы
- [ ] Восстановился сон и намаз
- [ ] Пациент перестал звонить

5. Что входит в карточку случая из пяти строк?
- [ ] Диагноз, прогноз, цена, отзыв, рекомендация
- [x] Дата и жалоба → зона и вид → что читали и сколько → реакция и выход → итог через 72 часа и 7 дней
- [ ] Только имя и дата
- [ ] Список всех прочитанных сур без реакции

6. Какие доказательства нужны, чтобы назвать случай колдовством, и почему слух не считается доказательством?
- [ ] Достаточно слов пациента и его родственников
- [x] Прямое наблюдение, запись, свидетели; слух и скриншот без контекста — не доказательство, а клевета — вред
- [ ] Достаточно реакции на чтение
- [ ] Доказательства не нужны, если ракый уверен
