1. Что проверяет защита двух случаев — в отличие от теста модуля?
- [ ] Знание арабской грамматики формул
- [ ] Количество прочитанных книг курса
- [x] Умение вести приём целиком от входа до вывода и честность в разборе
- [ ] Скорость произнесения аятов

2. Сколько случаев и какого набора выносятся на защиту?
- [ ] Три любых из дневника практики
- [x] Два из трёх принятых наставником случаев, из разных корневых групп
- [ ] Два самых успешных случая ступени 1
- [ ] Один случай по выбору наставника

3. Что обязательно присутствует в блоке «Граница безопасности» на защите?
- [ ] Обещание больше ошибаться не будет
- [x] Названные красные флаги: были/не были, как проверял, что сделал бы при каждом
- [ ] Статистика выздоровлений
- [ ] Пересказ Модуля 4 целиком

4. Что из перечисленного — недопустимый довод при диагнозе на защите?
- [ ] Ссылка на конкретные ответы пациента из опроса
- [ ] Ссылка на «зоны без чувства» в теле
- [x] «Мне показалось» и «система так посчитала»
- [ ] Ссылка на признаки из справочника классификации

5. Почему пациент описывается обезличенно?
- [ ] Чтобы экономить время защиты
- [ ] Потому что наставник не должен знать группу недуга
- [x] Потому что конфиденциальность пациента — обязанность раки (Модуль 12), даже перед своим наставником
- [ ] Так требует шаблон формы

6. Что происходит при несдаче одной из двух защит?
- [ ] Пересдается весь экзамен с самого начала
- [ ] Допуск аннулируется навсегда
- [x] Повтор только несданного случая — после исправленного письменного разбора
- [ ] Наставник закрывает случай сам

7. Что верно про период после успешной защиты?
- [ ] Супервизия заканчивается — дальше только самостоятельная работа
- [x] Допуск фиксируется, но первые месяцы — регулярные разборы с наставником; этика Модуля 11 действует всегда
- [ ] Защита заменяет входной ценз чтения
- [ ] Право вести приём передаётся вместе с паспортом другому ученику
