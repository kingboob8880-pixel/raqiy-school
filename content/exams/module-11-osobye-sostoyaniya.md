1. Какие шесть особых случаев выделены в главе?
- [ ] Сглаз, зависть, сихр, масс, узел, порча
- [x] Родовое поражение, истихваз, рабт, сихр аль-маут, ПНС, порча на дом
- [ ] Голова, грудь, живот, спина, плечи, ноги
- [ ] Дети, взрослые, пожилые, беременные, спортсмены, студенты

2. Из каких четырёх шагов состоит разбор истихваза и в каком порядке они идут?
- [ ] Азан, чтение, вода, печать
- [x] Расторжение договора → очищение от ширка → изгнание захватчика → принятие истинного Покровителя
- [ ] Изгнание → договор → очищение → покровительство
- [ ] Опрос, диагноз, чтение, отчёт

3. Почему нельзя «лечить род» без запроса и обвинять умерших предков?
- [ ] Потому что это долго
- [x] Работа начинается с запроса и согласия живого человека, а обвинение умерших — клевета; один обряд «на весь род» не заменяет личной работы
- [ ] Потому что родовых поражений не бывает
- [ ] Потому что это запрещено только для женщин

4. Каков приоритет действий, когда духовное поражение сочетается с угрозой телу?
- [ ] Рукья → безопасность → тело
- [x] Безопасность → сохранение тела → рукья
- [ ] Только рукья, тело подождёт
- [ ] Сначала диагностика, потом всё остальное

5. Где граница техники ПНС и что делать при неврологических симптомах?
- [ ] Границ нет, технику можно доводить до боли
- [x] Не доводить до боли; при онемении, слабости, нарушении речи или потере сознания не форсировать и направить к врачу
- [ ] При симптомах увеличить громкость чтения
- [ ] При симптомах заменить технику на дыхательные практики
