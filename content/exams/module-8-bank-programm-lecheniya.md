1. Какие три опоры должны быть в рассказе пациента, прежде чем составляется полная программа?
- [ ] Имя виновного, дата начала, стоимость лечения
- [ ] Название болезни, результаты анализов, назначение врача
- [x] Вид недуга, место направления, канал или обстоятельство усиления
- [ ] Жалоба, возраст, семейное положение

2. Когда ставится финальная защита в курсе?
- [ ] По календарю: с последнего дня срока
- [ ] В первый же день, чтобы прикрыть пациента
- [ ] Только после защиты от возврата зла
- [x] Только когда чистка дала результат, а не по календарю

3. Где в сеансе читается восстановительный блок из семи просьб?
- [ ] В самом начале, до анализа
- [ ] После финальной защиты
- [x] После основного чтения и до финальной защиты
- [ ] Он опционален и каждый раз в другом месте

4. Как выбирается срок курса по тяжести?
- [ ] Всегда 40 дней, независимо от недуга
- [ ] Лёгкое — 1 день, среднее — 3, тяжёлое — 10
- [x] Лёгкое — 3 дня, среднее — 7, тяжёлое/застарелое — 14
- [ ] Срок назначает наставник индивидуально

5. Из чего состоит четырёхслойная финальная защита?
- [ ] Фатха, Бакара, Ихляс, Муаввизатан
- [ ] Вода, масло, хна, соль
- [ ] Доа, аят, заклинание, прикосновение
- [x] Хифз + садд + худжуб + хисн

6. Почему при джинне/масс заклинания закрытия дверей читаются строго после изгнания?
- [ ] Так красивее порядок сеанса
- [ ] Двери закрываются только на рассвете
- [x] Иначе можно «запереть» сущность внутри тела
- [ ] Закрывание дверей отменяет чистку

7. Какая формула намерения составлена правильно?
- [ ] «Ради Аллаха, от всего плохого — ×40»
- [ ] «Чтобы всё стало хорошо — ×5»
- [ ] «Ради Аллаха, исцели — без числа»
- [x] «Ради Аллаха, чтобы Аллах развязал узлы — ×70»

8. Что делает эталон 10, если носитель воздействия уничтожен, а связь держится?
- [ ] Считает связь прерванной и закрывает курс
- [ ] Ищет второй носитель догадками
- [ ] Пропускает критерий, раз носителя нет
- [x] Критерий разрыва несёт формулу разрыва предполагаемой связи — без пропуска
