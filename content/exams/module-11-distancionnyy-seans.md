1. Какие четыре этапа включает дистанционный сеанс?
- [ ] Звонок, оплата, чтение, прощание
- [x] Связь, образ, чтение, обратная связь — требования те же, что при личном приёме
- [ ] Диагноз, прогноз, курс, контроль
- [ ] Осмотр, пальпация, чтение, отчёт

2. Почему дистанционная работа не даёт права ставить диагноз на расстоянии?
- [ ] Потому что связь нестабильна
- [x] Духовный диагноз ставится по совокупности признаков и проверяется повторно, а телесные симптомы мы не диагностируем
- [ ] Потому что пациент может обмануть
- [ ] Потому что так принято в других школах

3. Что делать, если во время дистанционного чтения у человека приступ?
- [ ] Продолжать чтение громче
- [x] Обеспечить физическую помощь рядом с человеком, а не держать его «на проводе»; чтение — после или параллельно
- [ ] Завершить сеанс и перезвонить завтра
- [ ] Попросить пациента подождать до конца цикла

4. Перечисли семь шагов самоисцеления.
- [ ] Вуду, азан, чтение, вода, масло, сон, отчёт
- [x] Сесть прямо → чтение про себя и вслух → концентрация на теле → «аркый нафсий ва баданий» → назвать поражение → «Аллаху яшфини» → повторять цикл до облегчения
- [ ] Опрос, осмотр, диагноз, программа, сеанс, контроль, закрытие
- [ ] Только «Аллаху яшфини» 100 раз

5. Почему отсутствие мгновенного результата при самоисцелении не означает, что «не сработало»?
- [ ] Потому что результат не важен
- [x] Оценка идёт по динамике, а не по одному сеансу: самоисцеление — не тест на веру
- [ ] Потому что нужно читать громче
- [ ] Потому что причина всегда телесная
