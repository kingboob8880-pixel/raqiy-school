1. Чем отличается заклинание на действие (с «ли» — لِـ) от обычного заклинания (с «мин» — مِنْ)?
- [ ] Ничем не отличается
- [ ] Заклинание на действие тише по голосу
- [x] «Мин» — заклинание «от» (защита), «ли» — заклинание «для/чтобы» (активное действие: вывести, сжечь, развязать)
- [ ] «Ли» используется только для воды

2. Что такое комбинированная формула максимальной мощи?
- [ ] Чтение трёх разных сур подряд
- [ ] Заклинание без атрибутов
- [x] Формула, сочетающая атрибут Аллаха + «от» (что убирается) + «для» (что происходит вместо этого)
- [ ] Чтение одного аята сто раз

3. Нужно не защититься, а развязать узел сихра. Какую конструкцию выбираешь по уроку?
- [ ] «Мин» — «арки … мин …», потому что она мягче
- [x] «Ли» — активное «для/чтобы» (развязать, вывести, сжечь)
- [ ] Любую — предлог не меняет действия
- [ ] Только дуа без глагола направления

4. Просят «усилить до максимума». Из чего складывается комбинированная формула максимальной мощи?
- [ ] Из десяти разных сур подряд
- [x] Атрибут Аллаха + «от» (что убирается) + «для» (что ставится вместо) — в одной связке
- [ ] Из одного имени, повторённого 100 раз
- [ ] Из имени пациента на арабском
