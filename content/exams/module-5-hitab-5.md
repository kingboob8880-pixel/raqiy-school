1. Из каких пяти частей состоит полная формула?
- [ ] Обращение, поклон, салам, дуа, печать
- [x] Обращение к Источнику, действие, предмет, содеявший, автор предмета
- [ ] Вода, масло, мёд, соль, уксус
- [ ] Нийя, якын, ихляс, таухид, дуа

2. Что происходит, если при чтении формулы не держать в уме предмет и место?
- [ ] Формула становится сильнее
- [x] Пропадает адресность: формула превращается в проговаривание, а не в обращение
- [ ] Ничего не меняется, важен только текст
- [ ] Увеличивается число повторений

3. Какие шесть пунктов проверяют до чтения формулы?
- [ ] Громкость, темп, число повторов, поза, вода, масло
- [x] Обращение только к Аллаху, понятность слов, ясность смысла, отсутствие невыполнимых обещаний, отсутствие управления джинном, сила не приписывается словам отдельно от Аллаха
- [ ] Возраст пациента, пол, диагноз, зона, вид, стаж
- [ ] Наличие свидетелей, махрама, времени, места, света, тишины

4. Чем рабочая формула отличается от формулы из Сунны и каков её статус?
- [ ] Ничем: они равны по статусу
- [x] У рабочей формулы нет прямого основания в Откровении: это пример практики, и требования к пониманию её смысла выше
- [ ] Рабочая формула запрещена полностью
- [ ] Рабочая формула заменяет Коран

5. Когда применяется рукия слов и какие у неё границы?
- [ ] Всегда, с публичным называнием имени обидчика
- [x] При устойчивой связи с человеком и остатке после общей рукьи; имя не называют без оснований, реакция — сигнал, а не доказательство вины
- [ ] Только если пациент сам требует наказать виновного
- [ ] Только на воду
