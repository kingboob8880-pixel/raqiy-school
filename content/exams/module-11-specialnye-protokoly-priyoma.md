1. Что делает специальный протокол с программой по 10 критериям?
- [ ] Заменяет её целиком, базовая программа не читается
- [ ] Сокращает её до трёх главных критериев
- [x] Дополняет или переориентирует формулы — но не удаляет ни один критерий
- [ ] Применяется только если пациент сам о нём попросил

2. Симптом повторяется у бабушки, матери и дочери. Какой протокол и какой порядок?
- [ ] Коллективный: полный курс каждой по отдельности
- [ ] Внутренней раны: упор на критерий 3
- [x] Родовой: сначала Р1 и Р2, затем основные 10
- [ ] Снов: чтение перед сном каждой

3. При пищевом воздействии каков порядок применения?
- [ ] Основные 10 → затем вода → затем желудок
- [x] Чтение над водой → направленное чтение на желудок → основные 10
- [ ] Только вода, критерии не нужны
- [ ] Назначить диету, затем программу

4. В коллективном лечении поражён ребёнок. Кто читает и как составляются формулы?
- [ ] Назначается взрослый пациент, ребёнка лечат общим чтением над домом
- [x] Читает родитель, формулы составляются на имя ребёнка
- [ ] Ребёнок читает сам под присмотром
- [ ] Приём не проводится до совершеннолетия

5. Носитель колдовства уничтожен. Что применимо?
- [ ] Формула возврата вреда на изготовителя
- [ ] Лечение прекращается — связь оборвана сама
- [x] В критерии 7 или 9 — формула разрыва предполагаемой связи, без утверждения, что связь существовала
- [ ] Особый критерий 11 вместо девятого

6. Пациент проблему не признаёт, привёл муж. Что обязательно в протоколе осознавания?
- [ ] Диагноз ставится по словам мужа и начинается полный курс
- [ ] Чтение над пациентом без его ведома
- [x] Чтение сопровождающим с согласия пациента, формулы на имя пациента, без принуждения
- [ ] Отказ в помощи до личного обращения пациента

7. Режим «Открытие путей Корана» применяется как…
- [ ] Самостоятельная замена анализу и десяти критериям
- [ ] Обязательный первый шаг любого приёма
- [x] Подключение после выбора основного направления, ничего не заменяя
- [ ] Исключительно для блокировки удела (ар-ризк)
