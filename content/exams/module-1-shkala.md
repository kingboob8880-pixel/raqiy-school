1. Чем шкала усиления души является по замыслу автора?
- [ ] Рангом и уровнем посвящения, который выдаётся за заслуги
- [x] Рабочей картой состояния души и дальности влияния, а не шариатской степенью
- [ ] Гарантией результата при достижении седьмой ступени
- [ ] Медицинской шкалой для постановки диагноза

2. Какие три оси образуют шкалу?
- [ ] Вера, пост, хадж
- [x] Душа, влияние, устойчивость
- [ ] Голос, дыхание, громкость
- [ ] Прошлое, настоящее, будущее

3. В чём правило порядка между душой и влиянием?
- [ ] Влияние можно поднять выше души, если громче читать
- [x] Влияние не поднимается выше души: сначала состояние, затем действие
- [ ] Душа и влияние не связаны между собой
- [ ] Влияние важнее души, потому что его видно

4. Какой критерий соответствует ступени «Нийя»?
- [ ] Я не могу сказать, куда читал
- [ ] Я читаю сразу после четырёх шагов входа
- [x] Формула намерения складывается до чтения: названы субъект, объект, действие, инструмент и цель
- [ ] Через 21 день человек читает сам

5. Чем ступень «Кальб» отличается от громкого чтения без внутренней работы?
- [ ] Ничем: это одно и то же, если читать громко
- [x] Ей предшествует беззвучное накопление намерения, после которого слово обретает вес
- [ ] Она требует крика и напряжения
- [ ] Она измеряется количеством прочитанных страниц

6. Что относится к шести разрушителям ступени?
- [ ] Пост, садака, тахаджуд
- [x] Показуха, гордыня, страх, рассеянность, сомнение, спешка
- [ ] Вуду, тишина, свет, поза
- [ ] Длинный курс, короткий курс, профилактика

7. Почему пятнадцать недугов нафса разбирают по одному-два за сеанс?
- [ ] Потому что остальные недуги не существуют
- [x] Потому что это зажимы, которые живут в разных органах и не снимаются одним общим чтением
- [ ] Потому что сеанс должен длиться не больше минуты
- [ ] Потому что все недуги лечатся только медикаментами

8. Какие четыре признака проверяются после прохода?
- [ ] Громкость, скорость, интонация, пауза
- [x] Симптом, функция, реакция, тело
- [ ] Возраст, пол, вес, рост
- [ ] Сон, сглаз, зависть, колдовство

9. Что делать при результате 3 / 4?
- [ ] Закрыть случай и больше не проверять
- [x] Сделать второй проход по той же зоне

- [ ] Обвинить пациента в слабой вере

10. Что шкала запрещает делать с результатом и сроком?
- [ ] Говорить о них только с «иншаАллах»
- [ ] Записывать результат в журнал
