1. Сколько повторений намерения в сердце рекомендуется для «заряжения» перед сеансом рукьи?
- [ ] 3–7 повторений
- [ ] 10–20 повторений
- [x] Минимум 40, оптимум 70, максимум 100 и более
- [ ] 33 повторения

2. Какие три ступени заряжения намерения названы в учебнике, в правильном порядке?
- [ ] Удержание, формулировка, повторение
- [x] Формулировка (ат-таквин), повторение (ат-такрар), удержание (аль-имсак)
- [ ] Повторение, омовение, уединение
- [ ] Формулировка, чтение, печать

3. С каких трёх ступеней начинается полная последовательность волевого акта сеанса?
- [ ] Формулировка намерения, заряжение, направление взгляда
- [ ] Открытие уст, чтение, завершение и печать
- [x] Уединение, ритуальная чистота (вуду), прибежище от шайтана
- [ ] Прибежище, взгляд, печать

4. Ученик повторил намерение пять раз в голове и сразу начал сеанс; к середине намерение «растаялось». Что пропущено по правилу заряжения?
- [ ] Ничего, пяти раз достаточно
- [x] Не набрана норма заряжения (минимум сорок) — намерение не закрепилось удержанием (аль-имсак)
- [ ] Нужно было читать громче
- [ ] Пропущено омовение
