1. Из каких шести блоков состоит личный режим защиты целителя?
- [ ] Вода, масло, мёд, соль, уксус, ладан
- [x] Ихляс и Сунна, молитвы вовремя, зикры, аль-Бакара, омовение, дуа выхода
- [ ] Пост, уединение, молчание, голос, дыхание, сон
- [ ] Диагноз, прогноз, курс, контроль, отчёт, оплата

2. Какие пять шагов включает защита дома пациента и в каком порядке они идут?
- [ ] Азан → тахриж → окропление → чтение → уборка
- [x] Защитные суры при входе → тахриж трижды → азан → окропление водой → Аят аль-Курси и аяты преграды в углах
- [ ] Окропление → азан → тахриж → чтение → отчёт
- [ ] Только азан и окропление

3. Что читается в каждом углу комнаты и зачем нужен аят преграды?
- [ ] Только аль-Фатиха, для благословения еды
- [x] Аят аль-Курси с указанием вправо, влево, вверх и вниз, и аят преграды (36:9) — чтобы закрыть стороны пространства
- [ ] Только дуа о ризке
- [ ] Ничего, достаточно азана

4. Для чего используются благовония в этом методе, а для чего — нет?
- [ ] Для изгнания джиннов из дома
- [x] Только для аромата; не как средство влияния на джиннов и не как «защитный» предмет
- [ ] Для «зарядки» талисманов
- [ ] Благовония запрещены полностью

5. Что защита дома не заменяет и почему она не даёт гарантий?
- [ ] Не заменяет рукью и гарантирует защиту навсегда
- [x] Не подменяет уборку, ремонт и безопасность, не закрывает дом навсегда и не превращается в обряд без запроса живущих
- [ ] Не заменяет оплату
- [ ] Не заменяет визит врача, но гарантирует результат
