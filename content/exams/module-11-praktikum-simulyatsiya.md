1. Пациентка жалуется: живёт в новом доме три месяца, у неё и мужа давление в груди под утро, сын стал вялый, «будто кто-то стоит рядом», вне дома отпускает. Какой главный вид поражения по совокупности признаков?
- [ ] Одержимость джинном — из-за ощущения присутствия
- [x] Коллективное (домовое) воздействие — привязка к дому, похожие симптомы у троих, улучшение вне него
- [ ] Только сглаз — из-за зависти соседей
- [ ] Медицинская причина — к врачу, рукья не нужна

2. Что меняется, когда ты выставляешь приоритет критериев по виду недуга?
- [ ] Состав программы — часть критериев выбрасывается
- [x] Только порядок внутри сеанса; все десять критериев выполняются
- [ ] Количество повторов (×5 становится ×1)
- [ ] Ничего не меняется, приоритет символический

3. На Part 0 (входе) взрослая пациентка в порядке, но её ребёнок «вялый третий день с температурой». Что правильно?
- [ ] Читать на всю семью по общему протоколу сразу
- [x] Ребёнка — сначала к врачу; рукья рядом как поддержка, а не вместо осмотра
- [ ] Отказать всей семье в приёме
- [ ] Игнорировать ребёнка, работать только со взрослыми

4. В рассказе всплывает, что найденный ранее носитель (свёрток на имя) уже сожжён, но связь держится. Какой шаг программы это закрывает?
- [ ] Пропустить критерий — предмета больше нет
- [ ] Вернуть вред на человека, сжёгшего носитель
- [x] Формула разрыва предполагаемой связи внутри критерия 7 или 9 — сам критерий не пропускается
- [ ] Начать сеанс заново с поиска нового носителя

5. Что считается «подтверждением» в таблице поражения, а что — домысливанием?
- [ ] Достаточно одного похожего симптома, чтобы записать вид
- [x] Источник объявляется установленным, только если о нём сказал сам пациент; иначе — «не установлен»
- [ ] Подтверждением служит процент уверенности из системы
- [ ] Главное — интуиция читающего
