1. Как входит наступленное колдовство (сихр аль-маршуш) в тело человека?
- [ ] Через глаза при чтении заклинания
- [ ] Через еду
- [x] Через стопы, когда человек наступает на заколдованное место, и поднимается вверх по телу
- [ ] Через дыхание

2. Какой аят особенно подходит для наступленного колдовства и содержит слова «куда бы он ни пришёл»?
- [ ] Аят аль-Курси (аль-Бакара, 2:255)
- [x] «Ва алки ма фи яминика тальккаф ма сана'у...» (Та Ха, 20:69)
- [ ] Аль-Фатиха
- [ ] Сура аль-Ихлас

3. Какой порядок чтения рекомендуется при съеденном колдовстве (сихр аль-ма'куль)?
- [x] Аяты перед заклинанием — сначала чтение, чтобы Аллах Своим Словом начал разрушать материал в животе, затем направить заклинание на органы
- [ ] Заклинание перед аятами
- [ ] Только аяты без заклинания
- [ ] Только заклинание без аятов

4. Человек замечает: после ходьбы по старому двору тяжести поднимаются от стоп к ногам и выше. Какой вид по каталогу и куда направить чтение?
- [ ] Сглаз — сверху, от головы
- [x] Наступленное колдовство (сихр аль-маршуш) — стопы и восходящий путь; аят «алки ма фи яминик…» (Та Ха, 20:69)
- [ ] Съеденное — живот
- [ ] Масс — только грудь
