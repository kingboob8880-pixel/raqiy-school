1. Что, по правилу точного отнесения, может быть объявлено установленным источником вреда?
- [ ] Вид недуга, похожий по одному симптому на описание из метода
- [x] Только то, о чём сказал сам пациент в своём рассказе
- [ ] Автоматический вывод системы RUKYA Pro до перепроверки
- [ ] Любая догадка раки, если она подтвердилась реакцией на чтение

2. Пациент говорит: истощение приходит только после общения с определённым человеком, а не постоянно. Это указание на…
- [ ] Постоянное джинн-воздействие
- [ ] Пищевое воздействие: подмешивание в еду или питьё
- [x] Энергетическое поглощение при контакте
- [ ] Родовое воздействие

3. Носитель колдовства найден и уничтожен. Что меняется в программе?
- [ ] Лечение прекращают — носителя нет, делать нечего
- [ ] Все критерии пропускаются, остаётся только защита
- [x] Вместо формулы возврата к предмету — формула разрыва связи внутри критерия 7 или 9
- [ ] Возврат вреда направляется на того, кто сделал носитель

4. Результат протокола тревожных снов оценивают по…
- [ ] Силе реакции во время чтения перед сном
- [x] Качеству сна и изменению повторяющегося образа
- [ ] Количеству пота и слёз на утреннем сеансе
- [ ] Пересказу сна пациентом в деталях до прочтения

5. Пациентку приводит муж: она проблему не признаёт и читать не согласна. Как ведётся приём?
- [ ] Диагностика и формулы — по словам мужа, чтение без её ведома
- [x] Диагностика через слова сопровождающего, формулы — на имя пациентки, только с её согласием
- [ ] Отказ: с духовно слепыми приём не проводится
- [ ] Назначается коллективный протокол на всю семью

6. «Внутри чёрный комок после предательства, вред чувствуется идущим изнутри, внешнего нет». Какое направление программы верное?
- [ ] Возврат зла на обидчика по критерию 1
- [ ] Пищевой протокол: проверить, не подмешали ли
- [x] Протокол внутренней духовной раны вместо возврата и аннулирования к внешнему источнику
- [ ] Родовый протокол: паттерн же повторяется в семьях

7. Какие два сигнала из рассказа отменяют запуск шаблона приёма вообще?
- [ ] Сильная реакция на чтение и всплеск в первый сеанс
- [ ] Отсутствие критики у пациента и его сомнения в рукье
- [x] Пассивные маркеры нежелания жить с отказом от еды и острая давящая грудная боль с отдачей в руку
- [ ] Повторяемость симптома у двух поколений и «стеклянные глаза» знакомого
