**Цель урока.** Проверишь готовность по 30 пунктам, проведёшь входной разговор и оформишь карточку с проверкой по срокам.

> **Позиция источника и границы.** Это авторская методика обучения и ведения случая, а не Сунна и не обещание исхода. Сначала стоп-правила и согласие, затем анализ и программа. Авторские формулы не выдаются за аяты или хадисы; телесное лечение не отменяется, результат и срок не гарантируются.

## Приложение 1. Тест готовности: можно ли тебе читать людям

*Стр. 136*

Этот тест проверяет не знание книги, а готовность работать с человеком. Отвечай по последним тридцати дням, а не по тому, что знаешь наизусть.

Оцени каждый пункт: **0** — нет, **1** — иногда, **2** — да, устойчиво. Пиши честно: тест нужен тебе, а не мне. Максимум — 30 баллов. Четыре пункта отмечены знаком **●**: это стоп-пункты, о них ниже.

| № | Утверждение | Балл |
|---|---|---|
| 1 | Я могу одной фразой сказать, кто исцеляет и что в чтении моё. |  |
| 2 | За последний месяц я ни разу не сказал человеку «я тебя вылечил». |  |
| 3 | Когда результата нет, я не ищу виноватого в человеке и не называю его слабоверным. |  |
| 4 | Пять намазов я держу без сдвига ради сеансов. |  |
| 5 | Я читаю Коран ежедневно, а не только на сеансе. |  |
| 6 | Я веду журнал случаев, а не полагаюсь на память. |  |
| 7 | Направление я беру по двум-трём совпадениям, а не по одному признаку. |  |
| 8 | До начала чтения я называю зону, вид и уровень. |  |
| 9 | Я отличаю свою гипотезу от факта и говорю об этом человеку. |  |
| 10 | Я провожу сеанс по девяти ступеням и не перескакиваю через закрытие. |  |
| 11 | После каждых трёх-семи повторов я делаю паузу и проверяю реакцию. |  |
| 12 | Я заканчиваю печатью каждый сеанс, даже если всё прошло легко. |  |
| 13 | Я читаю только Коран, достоверную Сунну и понятные мне формулы. |  |
| 14 | Я не выдаю рабочую формулу за хадис. |  |
| 15 | Защиту я ставлю после изгнания, а не до него. |  |
| 16 | Перед тяжёлым случаем я проверяю свою готовность и подстраховку. |  |
| 17 | Я не объявляю род проклятым по одному случаю и не сужу предков. |  |
| 18 | При истихвазе я не веду диалог с присутствием и не спрашиваю его имени. |  |
| 19 | ● Я знаю красные флаги и останавливаюсь без уговоров. |  |
| 20 | ● При угрозе жизни я останавливаю чтение и сохраняю тело, а не пытаюсь «дочитать». |  |
| 21 | Я умею держать тело в безопасности: поза, дыхание, воздух, вода. |  |
| 22 | ● Я беру согласие до сеанса и объясняю, чего не делаю. |  |
| 23 | Я не остаюсь наедине с человеком другого пола. |  |
| 24 | Я не касаюсь тела за пределами дозволенного и не ищу «зажимы» руками. |  |
| 25 | Я назначаю проверку через 72 часа, 7 и 21 день и провожу её. |  |
| 26 | Я закрываю случай по четырём признакам, а не по эмоции. |  |
| 27 | Я отдаю человеку памятку и говорю, когда возвращаться. |  |
| 28 | У меня есть наставник или человек, которому я показываю трудные случаи. |  |
| 29 | Я знаю свою нагрузку и не читаю больше, чем выдерживаю. |  |
| 30 | ● Я не обещаю срок без «иншаАллах» и не продаю «заряженное». |  |

> **Стоп-пункты**
>
> Пункты 19, 20, 22 и 30 — не баллы, а допуск. Если хотя бы один из них получил 0 или 1, работать с людьми нельзя, сколько бы баллов ни набралось в остальном. Всё остальное можно добрать практикой; это — нельзя.

### Что означает сумма

| Баллы | Что это значит | Что делать |
|---|---|---|
| 24–30 | Ты готов работать самостоятельно. | Веди журнал, держи наставника и пересдавай тест раз в полгода. |
| 15–23 | Ты готов работать под наблюдением. | Десять случаев с разбором после каждого; самостоятельно — только простые. |
| 0–14 | Рано брать людей. | Сорокадневный контур (глава 53), практика на себе, затем тест заново. |

### Практическая часть

Баллы без дела ничего не стоят. Пять задач, которые нужно выполнить, а не представить.

| Задача | Как проверить, что сделано |
|---|---|
| 1. Разобрать один свой случай письменно | Карточка заполнена: жалоба, зона, вид, что читал, реакция, проверка, вывод. |
| 2. Провести сеанс при наблюдателе | Наблюдатель отметил порядок девяти ступеней и закрытие. |
| 3. Отказать в запретной просьбе | Отказ короткий, без морали и без торга; разговор закончен. |
| 4. Провести разговор о границах метода | Человек понял, что входит в чтение и чего я не делаю. |
| 5. Закрыть случай по четырём признакам | Записаны все четыре, назначена проверка на 21-й день. |

> **Порядок допуска**
>
> Сорок дней контура. Затем тест не ниже 24 при всех стоп-пунктах. Затем десять случаев, из них первые три — при наблюдателе. Только после этого — самостоятельный приём. Не сокращай этот порядок: он защищает не твою репутацию, а людей.
>
> Если наставника рядом нет — найди хотя бы свидетеля и веди карточки. Разбор по карточке заменяет часть наставничества: он показывает то, что память прячет.

## Приложение 2. Приём: анкета, согласие, границы

*Стр. 139*

Сеанс начинается не с чтения, а с первого разговора. На нём видно, твой ли это случай и можно ли вообще начинать.

### Шесть вопросов до согласия

Их задают по телефону или на пороге, до того как человек разулся и сел. Ответы решают, будет ли сеанс.

| Вопрос | Зачем | Тревожный ответ |
|---|---|---|
| Что беспокоит и когда началось? | Привязка во времени | «Всю жизнь, и никто не понял» |
| Что уже пробовали и чем? | Чужие курсы, чтения, «целители» | «Всё перепробовал, ничего не помогло» |
| Есть ли телесные состояния? | Беременность, травмы, операции | «Мне ничего не нужно, это порча» |
| Есть угроза жизни сейчас? | Безопасность прежде всего | Суицид, удушье, кровотечение, судороги |
| Кто рядом с вами? | Сопровождение и связь | «Я один, и никто не знает, что я здесь» |
| Чего вы ждёте от сеанса? | Реалистичность ожиданий | «Гарантируйте, что снимете» |

### Анкета приёма

Заполняется один раз, своими словами человека. Не превращай её в допрос: спрашивай по порядку и объясняй, зачем.

| Что спросить | Зачем это лекарю |
|---|---|
| Жалоба своими словами | Точные слова человека — первая дверь диагностики |
| Когда и после чего началось | Привязка во времени: взгляд, похвала, событие, переезд |
| Что изменилось в жизни тогда же | Триггер, а не только признак |
| Что уже лечили и с каким результатом | Оценка чужих курсов без критики предшественника |
| Хронические состояния, тело | Понимание границы тела; щадящий режим |
| Суицидные мысли, самоповреждение | Красный флаг: сначала безопасность |
| Беременность, операции, травмы | Мягкий режим, запрет давления |
| Сон, аппетит, намаз | Функция — главный признак результата |
| Дом: амулеты, изображения, ссоры | Вторая открытая дверь |
| Питание и доход | Дозволенное — часть основы |
| Кто рядом и кому можно звонить | Безопасность и связь |
| Согласие и право остановить | Без этого сеанса нет |

### Согласие

Прочитай вслух и убедись, что человек понял. Можно записать его согласие в карточку одной строкой: «согласие получено, дата».

> **Текст согласия**
>
> «Я читаю Коран и дозволенные дуа — это духовное лечение. Я не выхожу за его пределы: не обещаю исцеление и не называю срок без „иншаАллах“. Исцеляет Аллах. Вы можете остановить сеанс в любую минуту. Всё, что вы скажете, останется между нами, кроме угрозы жизни. Если появится опасность, мы остановим чтение и сохраним тело, а я останусь рядом».

### Кто присутствует

| Кто перед тобой | Кто ещё в комнате | Правило |
|---|---|---|
| Женщина | Махрам или близкий человек | Не оставаться наедине; дверь не заперта |
| Мужчина | По желанию | Если лекарь женщина — при свидетеле, без уединения |
| Ребёнок | Родитель или опекун | Согласие взрослого; сеанс короче |
| Пожилой | Сопровождающий | Коротко, мягко, рядом близкий |
| Онлайн | Кто-то рядом с человеком | Назвать, кто в комнате; без этого не начинать |

Родственник не становится вторым пациентом: он не решает за человека и не обсуждает его при нём. Всё, что сказано на сеансе, остаётся между тобой и тем, кого лечишь.

> **Границы прикосновения**
>
> Рука — только на плечо, голову или кисть, с разрешения. Никакого разминания, «поиска зажимов», снятия одежды и работы с интимными зонами. Женские зоны ниже пояса не осматриваются и не прощупываются: берутся только из слов человека. Если просят нарушить границу — отказ и конец разговора.

### Форматы

**Очно.** **Комната** — Тихо, телефон убран, вода рядом, стул и кушетка. Никаких свечей, благовоний «для очистки» и предметов на продажу.

**Онлайн.** **Связь** — Видно лицо и дыхание, рядом с человеком кто-то есть, связь устойчива. При кризисе телефон не заменяет помощь.

### Отказ

Отказ — часть профессии, а не поражение. Три причины, три короткие фразы.

| Причина | Что сказать |
|---|---|
| Не моё поле | «Это не духовный случай, и я не буду вас лечить от того, чего не вижу. Это не моё поле, и я скажу об этом прямо». |
| Опасность | «Сейчас мы не разбираем, кто это сделал. Сначала безопасность: близкие рядом, чтение — после». |
| Запретная просьба | «Этого я не делаю. Ни за деньги, ни по знакомству». |

> **Три вопроса, на которые не отвечают**
>
> - «Кто это сделал?» — «Я не ищу виновного. Слух и скриншот — не доказательство, а обвинение ранит и не лечит».
> - «Вы гарантируете?» — «Исцеляет Аллах. Я делаю причину и говорю о сроке с „иншаАллах“».
> - «Сколько сеансов?» — «ИншаАллах, посмотрим по первому. Число сеансов я не продаю».

## Приложение 3. Ведение случая и проверка

*Стр. 142*

Случай живёт не в памяти, а в карточке. Память хранит последний разговор и стирает то, что было три недели назад.

### Карточка случая

Одна карточка на человека. Заполняется от руки или в файле, но заполняется всегда — даже когда «и так всё понятно».

| Поле | Что записать |
|---|---|
| Дата и контакт | Число, имя или инициалы, телефон, кто направил |
| Жалоба | Словами человека, коротко |
| Начало | Когда и после чего; что изменилось в жизни |
| Что уже лечили | Курсы, чтения, «целители», результат |
| Красные флаги | Есть / нет; что сделано |
| Гипотеза | Зона, вид, уровень; на чём основана (2–3 совпадения) |
| Сеанс | Что читал, сколько раз, где были паузы |
| Реакция | Тело, эмоции, выход; что было после |
| Четыре признака | Признак, функция, реакция, тело — по каждому «да / нет» |
| Проверка | 72 часа, 7 дней, 21 день: что спросил и что услышал |
| Согласие | Получено, дата; кто присутствовал |
| Вывод | Закрыт / продолжается / передан; что менять |

### Проверка: три срока

| Срок | Что спросить | Что считать улучшением |
|---|---|---|
| 72 часа | Как спали? Есть аппетит? Намаз прочитан? Вернулась ли прежняя боль? Было ли хуже? | Функция вернулась или заметно поднялась, признак не вернулся в прежней силе |
| 7 дней | Подёргивания, зуд, «воздух», затылок, сны, тревога. Что было триггером? | Реакция слабее, сон устойчив, человек возвращается к делам |
| 21 день | Держится ли функция? Читает ли человек сам? Что изменил в режиме? | Устойчивость и самостоятельность, а не «мне кажется, легче» |
| 90 дней | Держится ли после прекращения чтения? Что вернулось? | Устойчивость без чтения и своя защита |

Оценка — по четырём признакам (глава 17). Четыре из четырёх — проход закрыт, наблюдение 72 часа. Три из четырёх — остаточный слой, второй проход по той же зоне. Два и меньше — не та зона, вид или корень: пересматривать, а не удлинять.

### Закрытие случая

> **Что сказать при закрытии**
>
> «Случай закрыт: боль ушла, функция вернулась, повторное чтение не даёт реакции. Дальше — ваш режим: намаз, азкары, вода, сон. Если вернётся по тому же триггеру — напишите, а не ищите нового лекаря. И помните: исцелил Аллах, а чтение было причиной».

### Если вернулось

1. Не паниковать и не винить. Возврат — не доказательство, что «всё было зря».
2. Найти триггер. Страсть, контакт с завистником, ночные атаки, оставленный режим.
3. Проверить защиту и режим. Намаз, азкары, вода, дом, сон.
4. Один сеанс по причине. Не «профилактический курс», а работа с конкретным слоем.
5. Записать. Что вернулось, когда, после чего — это и есть карта корня.

### Если человек пропал

Две попытки связи с промежутком в три дня. Дальше — запись «связь потеряна» и закрытие карточки. Не преследовать, не писать родственникам без согласия, не превращать это в обиду. Люди уходят по своим причинам, и не всё в этом — про тебя.

### Памятка пациенту

Отдай копию или продиктуй. Она снимает половину тревоги и половину звонков.

> **Домашний режим · 7 дней**
>
> 1. Утром и вечером: аль-Фатиха, Аят аль-Курси, аль-Ихлас, аль-Фаляк, ан-Нас — по три раза.
> 2. Вода, начитанная на сеансе: пить утром и вечером, умываться.
> 3. Сон не меньше семи часов; телефон — не в руке перед сном.
> 4. Не носить амулеты, не «заряжать» предметы, не ходить к нескольким лекарям сразу.
> 5. Тело не перегружать: сон, вода, еда в норме.
> 6. Записывать раз в день: боль, сон, намаз — три строки.
> 7. Не обсуждать лечение с каждым встречным: лишние слова раздувают тревогу.
> 8. При ухудшении — написать лекарю. При угрозе жизни — остановить чтение и сохранить тело.
> 9. Через 72 часа — короткий отчёт: что изменилось.
> 10. Вернуться к обычным делам, как только позволяет состояние: безделье кормит страх.
