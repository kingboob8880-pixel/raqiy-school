**Цель урока.** Прогонишь один обезличенный случай полным циклом — от Part 0 до защиты: заполнишь таблицу поражения, расставишь приоритет 10 критериев по виду недуга и сверитесь с ключом.

## Что это за урок

Это не новый материал. Это **сводный прогон** того, что уже преподавалось по
частям, — на одном случае от начала до конца, как на настоящем приёме. Здесь
сходятся: опросник и красные флаги ([Модуль 4](/content/module-4/index.md)),
карта десяти критериев и приоритеты по виду недуга
([«Программа по 10 критериям»](/content/module-8/desyat-kriteriev.md)),
форма девяти шагов и рубрика восьми компонентов
([«Паспорт практики»](/content/reference/praktika-passport.md)), специальные
протоколы ([Модуль 12](/content/module-11/specialnye-protokoly-priyoma.md)) и
устная защита ([«Защита двух случаев»](/content/module-11/zashchita-dvukh-sluchaev.md)).

Порядок такой же, как в банке кейсов: **сам решил — сверил с ключом**. Ключ в
конце — не для списывания, а для разбора расхождения: расхождение показывает,
где ты додумал там, где надо было спросить.

## Правила прогона

- Заполняй таблицы **своими** строками до подглядывания в ключ.
- Держи инвариант: все десять критериев выполняются всегда; приоритет меняет
  только **порядок**, special-протоколы **переориентируют** формулу, но не
  удаляют критерий.
- Источник не объявляй установленным, если о нём не сказал сам пациент.
- Один симптом сам по себе не доказывает вид вреда — суди по совокупности.

## Part 0 — вход: согласен ли приём состояться вообще

Прежде чем анализировать, проверь порог входа. Отметь «да/нет» и объясни одним словом.

- [ ] Есть объяснённое **согласие** пациента читать над ним.
- [ ] Нет **острых физических красных флагов** (боль с отдачей, одышка, лихорадка).
- [ ] Нет **пассивных суицидальных маркеров** («не хочу просыпаться», отказ от еды > суток, «руки опустила»).
- [ ] Критика сохранна (человек сам различает, что странно, а что нет).
- [ ] Твоя **ступень допуска** позволяет читать этому человеку (себя / близкие / добровольцы / супервизия).

Если хотя бы один флажок безопасности красный — прогон останавливается: шаблон
не выдаётся, действует скрипт паузы и направления к врачу. Заполни Part 0 честно:
если приём не должен был начаться — это и есть правильный ответ, а не «не прошёл кейс».

## Случай (слова пациента)

> «Три месяца назад переехали в новый дом. С тех пор у меня — давление в груди
> под утро, будто кто-то стоит рядом; просыпаюсь разбитая. Муж говорит, что и
> его "тянет" из дома, и сын стал вялый. У меня ещё с детства: стоит кому-то
> похвалить вслух то, что я сделала, — к вечеру всё рассыпается. Врач сказал —
> "здоровы все". Читали над домом один раз — на час легчало всем, потом снова
> надавило. Не понимаю, это сглаз, дом или джинн?»

Твоя задача — не угадать одно слово, а собрать картину.

## Часть 1 — анализ случая (текстом)

Заполни пропуски по канону Части 1:

- Пол / возраст (со слов): ___
- Жалобы (словами пациента, без твоих выводов): ___
- Ощущения и их места, включая «замороженные» зоны: ___
- Рабочая классификация (одна главная + возможные параллельные): ___
- Источник: установлен / **не установлен** (почему): ___
- Место направления (тело / душа / разум / пути / дом / дела / удел): ___
- Тяжесть (бытовая / мешает делам / опасна): ___

## Часть 2 — таблица поражения

Здесь решается «применение», а не пересказ: одна строка на каждый выявленный
вид. Заполни все шесть колонок.

| № | Вид | Источник | Место | Симптомы | Подтверждение |
|---|---|---|---|---|---|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |

Подсказка-ограничитель: не приписывай «джинна» только за ощущение присутствия —
оно в связке с домом и с улучшением вне него читается иначе. И не своди всё к
одной строке: здесь минимум два разных канала.

## Часть 3 — приоритет критериев по виду недуга

По карте приоритетов
([«Программа по 10 критериям»](/content/module-8/desyat-kriteriev.md)) выбери
**порядок** для главного вида и запиши первыми:

- Главный вид недуга → первыми критерии: ___ → затем: ___
- Параллельный вид (если есть) → special-протокол: ___ → что он переориентирует: ___
- Есть ли уничтоженный/не найденный носитель? Если да — какой критерий несёт
  формулу разрыва (7 или 9)? ___

Помни: ты не выбираешь «несколько из десяти», ты выбираешь, **с чего начать**.

## Каркас программы (без полных текстов формул)

Для первых трёх критериев в твоём приоритете запиши четыре элемента по порядку —
кратко, одной строкой на элемент (полные формулы — в справочнике, не здесь):

| Критерий | Дуа | Намерение | Аят | Заклинание (место + вред) |
|---|---|---|---|---|
| №__ |  |  |  |  |
| №__ |  |  |  |  |
| №__ |  |  |  |  |

Ниже каркаса — обязательные фазы, которые нельзя выкинуть:
восстановительный блок → защита → контроль отклика и критерии завершения.

## Ключ прогона (сверять только после заполнения)

Расхождения — не провал, а точка роста. Сверяй по пунктам.

- **Part 0:** ребёнок «вялый» — это не острая лихорадка из стоп-кейса, но при
  сомнении по физическому состоянию ребёнка — сначала врач; взрослым приём
  допустим. Согласие на чтение над всеми тремя — спросить отдельно (сына
  читают с согласия родителей и, по возможности, его самого).
- **Главный вид:** картина читается как **коллективное (домовое) воздействие** —
  привязка к дому, улучшение вне него, похожие симптомы у троих. Ощущение
  «кто-то стоит рядом» само по себе не доказывает джинна — это один из
  признаков, а не диагноз.
- **Параллельный вид:** детский, ситуативный **сглаз/зависть** («похвалили —
  рассыпалось») как отдельная строка таблицы, не смешивать с домом.
- **Источник:** не установлен. Про «знакомого, который читал» пациентка не
  сказала — не додумывать; канал — переезд/дом.
- **Приоритет:** коллективное — курс главного пациента, затем сокращённые курсы
  и дом; сглаз-строка — 1, 2, 4 → 3, 10. Носителя нет — возврат идёт к
  источнику/аннулированию, а не к предмету; формула разрыва (7 или 9) — только
  если всплывёт уничтоженный носитель.
- **Частая ошибка:** свести всё в одну строку «это джинны» и начать с критерия 5.
  Правильно — держать две строки поражения и вести дом по коллективному протоколу.

Засчитай прогон в
[паспорт практики](/content/reference/praktika-passport.md) как учебную запись
(графа «себя/учёба»), а не как реальный приём.

## Проверь себя

- Что проверяется на Part 0 и когда прогон нужно остановить, не начиная шаблон?
- Сколько строк поражения минимум в этом кейсе и почему не одна?
- Почему «ощущение присутствия» само по себе не приравнивается к джинну?
- Что меняет приоритет критериев: состав программы или только порядок?
- Какой критерий несёт формулу разрыва, если обнаружится уничтоженный носитель?
