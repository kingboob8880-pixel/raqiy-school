# RUKYA PRO — сборка в rukya.exe

Это Vite+React-приложение «RUKYA PRO» (`src/`) плюс обёртка Electron
(`electron-main.cjs`), которая превращает его в отдельную программу для
Windows — устанавливается один раз, дальше запускается как `rukya.exe`,
без браузера и без интернета (кроме шрифтов Google Fonts, которые просто
не подгрузятся офлайн — приложение останется рабочим на системном шрифте).

*(Текст в `.bat`-файлах — на английском намеренно: кириллица в batch-файлах
ненадёжно работает в консоли Windows — на некоторых системах текст
рассыпается на нечитаемые обрывки, и cmd пытается выполнить их как
отдельные команды, роняя весь скрипт. Английский исключает этот класс
ошибок независимо от локали/кодовой страницы Windows.)*

## Готово ✓

Сборка выполнена (2026-07-20) — `release\RUKYA-PRO-Setup-1.0.0.exe` уже
собран и лежит в этой папке, можно раздавать ученикам сразу, без повторной

## Почему сборка не была готова сразу

Сборка `.exe` требует скачать бинарники Electron (~150–200 МБ, хостится на
GitHub) — сеть песочницы, в которой я работаю, блокирует именно этот адрес
(`release-assets.githubusercontent.com`), поэтому финальный шаг пришлось
сделать на вашем компьютере, где интернет обычный. Всё остальное (код
обёртки, конфигурация сборки, иконка) было готово заранее.

## Как пересобрать rukya.exe (на Windows)

1. Если ещё не установлен — поставьте [Node.js](https://nodejs.org) (LTS,
   отметьте "Add to PATH" при установке).
2. Откройте эту папку и запустите **`BUILD_EXE.bat`** (двойной клик).
3. Скрипт сам: поставит зависимости, соберёт приложение, соберёт
   установщик. Первый раз — 5–15 минут (зависит от интернета).
4. Готовый установщик появится в папке `release\` — файл вида
   `RUKYA-PRO-Setup-1.0.0.exe`.

## Что раздавать ученикам

Файл `release\RUKYA-PRO-Setup-1.0.0.exe` — это и есть установщик. Ученик
запускает его, выбирает папку (или соглашается со стандартной), после
установки на рабочем столе и в меню Пуск появляется ярлык «RUKYA PRO»,
исполняемый файл — `rukya.exe`. Дальше приложение работает полностью
локально — все данные (пациенты, планы) хранятся в самой программе
(IndexedDB), ничего никуда не отправляется.

## Другие скрипты в этой папке

- `START.bat` — режим разработки/предпросмотра в браузере
  (`npm run dev`, localhost:5173). Не нужен ученикам, полезен только вам,
  если захотите что-то поправить в `src/` и сразу увидеть результат.
- `REINSTALL.bat` — чистая переустановка зависимостей, на случай, если
  `npm install` выдал ошибку и `node_modules` осталась в сломанном
  состоянии.
- `BUILD_EXE.bat` — собственно сборка `rukya.exe` (см. выше).

## Если сборка падает с ошибкой "Cannot create symbolic link"

Известная особенность electron-builder на Windows — один из его
кэшируемых инструментов распаковывается через симлинки, а обычному
(не-администратору) пользователю Windows по умолчанию не разрешено их
создавать. Это не баг проекта, чинится один раз:

- **Вариант А (рекомендуется)** — Параметры → Конфиденциальность и защита →
  Для разработчиков → включить «Режим разработчика». Дальше `BUILD_EXE.bat`
  можно запускать обычным пользователем, без прав администратора.
- **Вариант Б** — щёлкнуть правой кнопкой по `BUILD_EXE.bat` →
  «Запуск от имени администратора».

После этого запустите `BUILD_EXE.bat` заново — предыдущие шаги (npm
install, vite build) уже выполнены и не повторятся заново, если только вы
не удалили `node_modules`/`dist`.

## Если после установки Windows Defender/SmartScreen ругается

Это ожидаемо для нового, ещё не имеющего репутации у Microsoft файла —
Electron-приложения без платной цифровой подписи (сертификат кода,
~200-400 $/год) всегда получают такое предупреждение при первом запуске.
Это не вирус — просто у файла ещё нет "истории". В окне SmartScreen нужно
нажать "Подробнее" → "Выполнить в любом случае". Если ученики будут
получать это через интернет (не лично от вас), стоит сопроводить установщик
коротким пояснением, что предупреждение ожидаемо, иначе часть людей просто
испугается и не установит.
