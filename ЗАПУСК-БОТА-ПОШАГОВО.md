## ШАГ 0. Отозвать старый токен — сделайте это первым

В репозитории лежал живой токен бота. Файл я удалил, но **из истории он не
исчез** — его достаёт одной командой любой, кто скачает репозиторий. Пока
токен не отозван, посторонний может читать переписку школы и писать вашим
ученикам от вашего имени.

1. Откройте в Telegram **@BotFather**
2. Отправьте `/mybots`
3. Выберите бота, которому принадлежит токен `8996853653:AAH5...`
4. **API Token** → **Revoke current token**

Старый токен перестанет работать. Это то, что нужно.

## ШАГ 4. Записать три значения в Firebase

Откройте PowerShell и перейдите в папку функций:

```powershell
cd "C:\Users\kingb\OneDrive\Desktop\Raqiy\functions"
```

Если давно не заходили — сначала войдите:

```powershell
firebase login
```

Теперь по очереди три команды. После каждой терминал попросит ввести
значение — вставьте и нажмите Enter:

```powershell
firebase functions:secrets:set TG_BOT_TOKEN
firebase functions:secrets:set TG_CHAT_ID
firebase functions:secrets:set TG_WEBHOOK_SECRET
```

- `TG_BOT_TOKEN` — токен из шага 1
- `TG_CHAT_ID` — число из шага 2
- `TG_WEBHOOK_SECRET` — строка из шага 3

**Если попросит включить Secret Manager API** — согласитесь, это нормально.

**Если скажет, что нужен тарифный план Blaze** — его придётся подключить.
Для вашей нагрузки это бесплатно: Firebase списывает деньги только сверх
щедрого бесплатного лимита, а у школы с несколькими десятками учеников до
него далеко. Карта нужна как подтверждение, а не как оплата.

## ШАГ 5. Выложить код

Из той же папки `functions`:

```powershell
firebase deploy --only functions
```

Это займёт 2–5 минут. В конце найдите в выводе строку с адресом функции —
что-то вроде:

```
Function URL (telegramWebhook(us-central1)): https://us-central1-rukya-school.cloudfunctions.net/telegramWebhook
```

**Скопируйте этот адрес.** Он нужен на следующем шаге.

Затем правила доступа — без них поле привязки Telegram останется открытым
для записи из браузера, а это дыра:

```powershell
cd ..
firebase deploy --only firestore:rules
```

## ШАГ 6. Связать бота с функцией

Возьмите три вещи: **ТОКЕН** (шаг 1), **АДРЕС** (шаг 5), **СЕКРЕТ** (шаг 3).

Соберите из них ссылку и откройте её в браузере:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС>&secret_token=<СЕКРЕТ>
```

Пример, как это выглядит целиком (значения свои):

```
https://api.telegram.org/bot1234567890:AAHxxxx/setWebhook?url=https://us-central1-rukya-school.cloudfunctions.net/telegramWebhook&secret_token=abc123def456
```

Браузер должен показать:

```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

Если `"ok":false` — проверьте, что токен и адрес вставлены целиком, без
пробелов и без угловых скобок.

## ШАГ 7. Проверить, что всё работает

**7.1. Бот отвечает.** Откройте @ruyka_school_bot, нажмите **Start**.
Должно прийти приглашение привязать аккаунт.

*Не ответил* → вернитесь к шагу 6, проверьте адрес. Логи функции:
Firebase Console → Functions → telegramWebhook → Логи.

**7.2. Привязка.** Откройте на сайте кабинет ученика (не админа — заведите
себе тестовую ученическую почту, если её нет), нажмите **Привязать
Telegram** → **Открыть бота и завершить привязку**. Бот должен ответить
«Аккаунт привязан».

**7.3. Чтение.** В боте: 📖 Модули → Модуль 1 → любой урок. Придёт текст с
кнопками «Дальше». У неоплаченного аккаунта — короткий отрывок и
предложение открыть курс. Это правильно.

**7.4. Общий прогресс — главная проверка.** Сдайте в боте экзамен любой
книги. Затем откройте эту же книгу на сайте: экзамен должен быть отмечен
сданным. Если отмечен — связка работает, дальше можно не волноваться.

**7.5. Наставник.** В боте: 💬 Спросить наставника → напишите что-нибудь.
Вам придёт сообщение с пометкой `#...`. **Ответьте на него реплаем**
(зажать сообщение → «Ответить») — ответ уйдёт ученику.

## ШАГ 8. Открыть себе весь курс

В кабинете админа у каждого ученика теперь есть колонка **«Всё открыто»** с
кнопкой 🔓. Нажмите её на своей тестовой ученической записи — откроются все
модули, все упражнения и полные тексты книг. Так вы увидите бота таким,
каким его видит оплативший.

## Что делать потом, не срочно

**Пересобирать данные бота после правок курса.** Если добавили урок,
модуль или упражнение — бот об этом не узнает, пока не выполните:

```powershell
cd "C:\Users\kingb\OneDrive\Desktop\Raqiy"
node scripts/build-course-data.mjs
cd functions
firebase deploy --only functions
```

**Сделать репозиторий приватным.** В его истории лежат и утёкший токен, и
полные тексты платных книг. GitHub Pages продолжит отдавать сайт публично.
Настройки репозитория → Danger Zone → Change visibility. Требует платного
плана для Pages из приватного репозитория.

**Перенести полные тексты книг в Firestore** — `scripts/seed-paid-content.mjs`,
инструкция внутри файла. Пока не сделано, платный текст лежит открытым в
репозитории, и пейвол держится только на том, что кнопку не показывают.

**Экзамены с ответами** тоже лежат открыто — кто заглянет в репозиторий,
увидит правильные варианты. Решается тем же переносом в Firestore.

## Если что-то пошло не так

**Бот молчит на всё.** Скорее всего вебхук не привязан или привязан с
другим секретом. Проверьте состояние:

```
https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo
```

Смотрите поля `url` (должен быть адрес вашей функции) и `last_error_message`.

**Бот отвечает «Код не найден».** Код живёт 15 минут. Нажмите «Привязать
Telegram» в кабинете заново.

**Уведомления вам не приходят.** Проверьте, что `TG_CHAT_ID` — именно ваш
номер из @userinfobot, и что после его записи вы заново выполнили
`firebase deploy --only functions`.

**«Ошибка» при отметке упражнения в кабинете.** Не задеплоены правила:
`firebase deploy --only firestore:rules`.

**Хочу проверить логику бота, не трогая Telegram:**

```powershell
cd "C:\Users\kingb\OneDrive\Desktop\Raqiy"
node scripts/smoke-tg-bot.cjs
```

Должно вывести список проверок и «Проверок провалено: 0».
